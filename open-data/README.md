# Open data

Anonymised and aggregated datasets from the SmartUrbanity pilots, released following FAIR principles.

Each dataset lives in its own folder, `<pilot>_<topic>_<YYYY>/`, with a `README.md` describing:

- source and collection method
- time period and spatial coverage
- variables and units
- anonymisation or aggregation applied
- licence and how to cite it

Raw or personal data collected in the pilots is never published here, in line with GDPR, the Swiss FADP and Türkiye's KVKK. Large datasets should be deposited on Zenodo and linked from here.
